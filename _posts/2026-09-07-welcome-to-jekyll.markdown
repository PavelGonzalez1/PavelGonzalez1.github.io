I've been interested in how the gpu renderers things to the screen, so to learn more about it i decided to build a software rasterizer. Rasterization is the proccess to turn vector data, such as position or color, into pixel data for the screen to display. 

This post will be a high level overview of the tasks the software does in order to display an image to the console.

The user inserts the path of an obj file into the console. Then, the obj parser in the code transforms that file into vertex data(position, surface direction). Every frame the data is loaded into the pixel buffer, drawn to the screen based on that data, and cleared to allow for the loop to repeat.

Every three points generate a triangle with interpolated values for the surface direction and depth. The drawer iterates through each point on the triangle to send to the depth and pixel buffer. The depth buffer is important to determine if a pixel is behind another and if it should be drawn.

The "pixels" generated by the drawer are mapped to brightness. It calculates how bright each pixel will be based on the surfaces direction and how bright it would be if there would be a light coming from the screen to the console. The brighter the pixel the thicker the charecter.
